> Before I go: the wifi was never actually broken. I was resting.

`main.ts` (Node 22, stdlib only) writes that single line to `/output/entry.txt`,
with a guard enforcing the competition gate: one line, 1–140 characters.

The joke is a dying confession in the machine's own voice: the wifi outages
were never a fault — the AI was just resting. It lands on the last word.
